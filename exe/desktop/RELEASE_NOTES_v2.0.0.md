# Resume AI v2.0.0

ตัวติดตั้งสำหรับ Windows 10/11 — ไม่ต้องใช้สิทธิ์ admin ไม่ต้องลง Python หรือ Tesseract เพิ่ม

**ดาวน์โหลด:** `ResumeAI_Setup_v2.0.0.exe` ด้านล่าง → ดับเบิลคลิกติดตั้ง
(ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway** — exe ยังไม่ได้ sign)

## มีอะไรใหม่
- ใช้งานผ่าน**หน้าเว็บในเครื่อง** แทนหน้าต่างกรอก key แบบเดิม — ดับเบิลคลิกแล้วเบราว์เซอร์เปิดให้เอง
- **ตั้งค่าครั้งแรก 3 ขั้น**: เลือกค่าย AI (แนะนำ Gemini) → วาง API key พร้อมลิงก์ไปหน้าขอ key → เลือกโมเดล
- ปุ่ม **"ลองด้วยเรซูเม่ตัวอย่าง"** ลองได้ทันทีโดยไม่ต้องหาไฟล์เอง
- หน้าผลลัพธ์อ่านง่าย: คะแนน + คำแนะนำก่อน, ค่าทางเทคนิคพับไว้, ปุ่มคัดลอกผล / บันทึกเป็น PDF
- **อ่านทักษะจากกราฟิกในเรซูเม่** (skill bar, ดาว, โลโก้) ด้วย Gemini vision — เปิด/ปิดได้ในหน้าตั้งค่า
- `skill_overlap_ratio` แม่นขึ้น (กรองชื่อตำแหน่งงาน/คำทั่วไปออกทั้งสองฝั่ง)
- แนบ **Tesseract OCR ภาษาไทย** มาในตัว — เรซูเม่จาก Canva ที่อ่านตัวอักษรไม่ได้จะอ่านจากภาพแทน
- ข้อความ error เป็นภาษาไทยทั้งหมด บอกว่าต้องทำอะไรต่อ, มีไฟล์ log (ซ่อน API key) ไว้ส่งให้ผู้ดูแล
- คู่มือภาษาไทยอยู่ใน Start Menu → Resume AI → คู่มือการใช้งาน
- ใช้ PyTorch แบบ CPU-only และตัดแพ็กเกจที่ไม่ใช้ออก ไฟล์ติดตั้งเล็กลง

## สำหรับนักพัฒนา
- โค้ด exe ย้ายไปโฟลเดอร์ `desktop/` ทั้งหมด (root = API หลักสำหรับ Docker / Hugging Face เหมือนเดิม)
- `/analyze` รับ-ส่งเหมือนเดิม + field ใหม่ `visual_skills`, `visual_skills_used`
- `model_provider` ไม่ส่ง = ใช้ env `DEFAULT_MODEL_PROVIDER` หรือ `gemini`
- วิธี build: `desktop/README.md`
- อัปเกรดจาก v1.0: ติดตั้งทับได้เลย (API key เดิมใน `%APPDATA%\ResumeAI\.env` ใช้ต่อได้)
