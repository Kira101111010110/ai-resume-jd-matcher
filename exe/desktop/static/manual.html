คู่มือการใช้งาน Resume AI

โปรแกรมคัดกรองเรซูเม่ด้วย AI ที่ทำงานบนเครื่องของคุณ · Windows 10/11

  1. ติดตั้งโปรแกรม
  2. ขอ Gemini API key
  3. ตั้งค่าครั้งแรก
  4. วิเคราะห์เรซูเม่และอ่านผล
  5. เปลี่ยน key / เปลี่ยนโมเดล
  6. แก้ปัญหาที่พบบ่อย และการส่งไฟล์ log

1. ติดตั้งโปรแกรม

  1. ดับเบิลคลิกไฟล์ ResumeAI_Setup_v2.0.0.exe (ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ และไม่ต้องติดตั้ง Python หรือโปรแกรมอื่นเพิ่ม)
  2. ถ้ามีหน้าจอสีน้ำเงิน “Windows protected your PC” (Windows ป้องกันพีซีของคุณ) ขึ้นมา — เป็นเพราะโปรแกรมนี้ยังไม่ได้ซื้อใบรับรองจาก Microsoft ไม่ได้แปลว่ามีไวรัส:
    1. กดข้อความ “More info” (ข้อมูลเพิ่มเติม)
    2. กดปุ่ม “Run anyway” (เรียกใช้ต่อไป) ที่ปรากฏขึ้นมา
[ภาพ: หน้าจอ “Windows protected your PC” พร้อมลูกศรชี้ “More info” และ “Run anyway”]
  1. กด ติดตั้ง รอประมาณ 1–3 นาที (ไฟล์ค่อนข้างใหญ่เพราะมีโมเดล AI อยู่ในตัว)
  2. หน้าสุดท้ายติ๊ก “เปิด Resume AI เลย” ไว้ แล้วกด เสร็จสิ้น

หลังติดตั้งจะมีไอคอน Resume AI บนเดสก์ท็อป และใน Start Menu (มีคู่มือนี้อยู่ในนั้นด้วย)

การเปิดโปรแกรมแต่ละครั้ง

  • ดับเบิลคลิกไอคอน Resume AI → ไอคอนเล็ก ๆ จะขึ้นที่มุมขวาล่างของจอ (ข้างนาฬิกา) และมีข้อความ “กำลังเปิด Resume AI…”
  • เบราว์เซอร์จะเปิดหน้าเว็บของโปรแกรมให้เองภายในไม่กี่วินาที โปรแกรมไม่ได้ส่งเรซูเม่ไปไว้บนเว็บไซต์ใด — หน้าเว็บนี้อยู่บนเครื่องของคุณเอง
  • ช่วงประมาณ 1 นาทีแรก ด้านบนจะมีแถบ “กำลังเตรียมระบบ AI…” รอจนแถบหายไปจึงจะกดวิเคราะห์ได้ (ระหว่างนั้นตั้งค่าหรือกรอกข้อมูลรอได้เลย)
  • ถ้าปิดหน้าเว็บไปแล้ว: ดับเบิลคลิกไอคอน Resume AI อีกครั้ง หรือคลิกขวาไอคอนที่มุมขวาล่าง → เปิดหน้าเว็บ
  • เลิกใช้: คลิกขวาไอคอนที่มุมขวาล่าง → ออก
[ภาพ: ไอคอน Resume AI ที่มุมขวาล่าง และเมนูคลิกขวา “เปิดหน้าเว็บ / เปิดโฟลเดอร์ log / ออก”]

2. ขอ Gemini API key (ฟรี)

API key คือ “รหัสผ่าน” ที่ให้โปรแกรมใช้บริการ AI ของ Google ได้ ทำครั้งเดียว

  1. เปิด aistudio.google.com/apikey แล้วเข้าสู่ระบบด้วยบัญชี Google (Gmail)
  2. ถ้าเพิ่งใช้ครั้งแรก ให้กดยอมรับข้อตกลงการใช้งาน
  3. กดปุ่ม “Create API key” (ถ้าระบบถามให้เลือกโปรเจกต์ เลือกตัวที่มีอยู่ หรือกดสร้างใหม่ก็ได้)
  4. กดปุ่มคัดลอกที่อยู่ข้าง key ที่ได้ (key ขึ้นต้นด้วย AIza… หรือ AQ.…)
[ภาพ: หน้า Google AI Studio ชี้ปุ่ม “Create API key” และปุ่มคัดลอก]

อย่าส่ง key ให้คนอื่นหรือโพสต์ในที่สาธารณะ — ใครมี key ก็ใช้โควตาของคุณได้ ถ้าเผลอเปิดเผยให้กลับไปหน้าเดิมแล้วลบ key นั้นทิ้ง แล้วสร้างใหม่

ใช้ OpenAI หรือ Claude ได้เช่นกัน (ต้องเติมเครดิตในบัญชีก่อน) แต่แนะนำ Gemini เพราะใช้ฟรีได้ ให้ผลดีที่สุดในการทดสอบ และใช้อ่านทักษะจากกราฟิกในเรซูเม่ได้

3. ตั้งค่าครั้งแรก

เปิดโปรแกรมครั้งแรก หน้าเว็บจะพาไปหน้า ตั้งค่าครั้งแรก เอง มี 3 ขั้น:

  1. เลือกค่าย AI — Gemini ถูกเลือกไว้ให้แล้ว (มีป้าย “แนะนำ”) กด ถัดไป
  2. ใส่ API key — คลิกในช่อง แล้วกด Ctrl+V วาง key ที่คัดลอกมา กด ตรวจสอบ key
  3. เลือกโมเดล — ตัวที่มี ★ ถูกเลือกไว้ให้แล้ว (ถ้าไม่แน่ใจ ใช้ตัวนี้) กด บันทึกและเริ่มใช้งาน
[ภาพ: หน้าตั้งค่าครั้งแรก ขั้นที่ 2 ใส่ API key]

ตั้งครั้งเดียวพอ ปิดแล้วเปิดโปรแกรมใหม่ไม่ต้องใส่ key ซ้ำ (key เก็บไว้ในเครื่องนี้เท่านั้น)

4. วิเคราะห์เรซูเม่และอ่านผล

ลองกับเรซูเม่ตัวอย่างก่อน

ในแท็บ วิเคราะห์ กดปุ่มใดก็ได้ในกล่อง “ลองด้วยเรซูเม่ตัวอย่าง” — มี 3 ใบที่สมัครตำแหน่งเดียวกัน (เล่าเรื่องดี / เขียนเป็นรายการคำ / ทักษะเป็นโลโก้) ลองกดทีละใบแล้วเทียบผลกันได้

วิเคราะห์เรซูเม่ของคุณเอง

  1. กด Choose File เลือกไฟล์เรซูเม่ (PDF ไม่เกิน 10 MB)
  2. กรอก ตำแหน่งงาน และ คณะ/สาขาที่รับ (ไม่บังคับ แต่ช่วยให้ผลแม่นขึ้น)
  3. วาง รายละเอียดงาน (คุณสมบัติ ทักษะที่ต้องการ) — ช่องนี้จำเป็น
  4. กด วิเคราะห์ รอประมาณ 10–60 วินาที
[ภาพ: หน้าผลการวิเคราะห์ทั้งหน้า]

ความหมายของผลแต่ละส่วน

ส่วนความหมาย
คะแนนความเหมาะสม (0–100)เรซูเม่ตรงกับรายละเอียดงานแค่ไหน โดยดูทั้งความหมายของเนื้อหา ทักษะที่ตรงกับงาน และคณะ/สาขา — ยิ่งสูงยิ่งตรง (75 ขึ้นไป = เหมาะสมมาก)
คำแนะนำ (ควรรับ / ไม่ควรรับ)ข้อสรุปจาก AI พร้อมเหตุผลสั้น ๆ ใช้ประกอบการตัดสินใจ ไม่ใช่คำตัดสินสุดท้าย
ทักษะที่พบในเรซูเม่ทักษะเฉพาะทาง (เช่น Python, Excel) และทักษะด้านอื่น (เช่น การทำงานเป็นทีม) — ป้ายเส้นประ “อ่านจากกราฟิก” คือทักษะที่เรซูเม่แสดงเป็นแถบกราฟ ดาว หรือโลโก้ ซึ่ง AI อ่านจากภาพมาให้
จุดเด่นเทียบกับงานสิ่งที่ผู้สมัครมีตรงกับงาน และสิ่งที่ยังขาด
การเล่าเรื่องในเรซูเม่ (ดี / ปานกลาง / น้อย)เรซูเม่เล่าว่า “เจอปัญหาอะไร → ทำอะไร → ได้ผลอย่างไร (มีตัวเลข)” หรือแค่ลิสต์ทักษะ — ใช้ดูคุณภาพการเขียนเรซูเม่
รายละเอียดเพิ่มเติม (กดเปิด)ค่าทางเทคนิค เช่น คะแนนดิบก่อนหัก สัดส่วนทักษะที่ตรง ความมั่นใจของแต่ละส่วน — ไม่จำเป็นต้องดูในการใช้งานปกติ

ถ้ามีกรอบสีเหลืองว่า “ไฟล์นี้อ่านตัวอักษรได้ไม่ครบ…” แปลว่าไฟล์ (มักทำจาก Canva) ไม่มีตัวอักษรให้อ่านตรง ๆ ระบบจึงอ่านจากภาพแทน ผลอาจคลาดเคลื่อนเล็กน้อย

ปุ่ม คัดลอกผล = คัดลอกสรุปเป็นข้อความไปวางใน Word/LINE/อีเมลได้ · ปุ่ม บันทึกเป็น PDF = เปิดหน้าพิมพ์ แล้วเลือกเครื่องพิมพ์เป็น “Microsoft Print to PDF” หรือ “บันทึกเป็น PDF”

5. เปลี่ยน key / เปลี่ยนโมเดล

  • ไปแท็บ ตั้งค่า → การ์ดของค่ายนั้น → เปลี่ยน key (วาง key ใหม่ → ตรวจสอบ → เลือกโมเดล → บันทึก)
  • เปลี่ยนโมเดล ทำได้โดยไม่ต้องใส่ key ใหม่ — ใช้เมื่อขึ้นข้อความว่าโมเดลไม่มีแล้ว หรือโควตาของโมเดลเดิมเต็ม
  • มี key หลายค่าย: กดวงกลมหน้าชื่อค่ายเพื่อเลือกค่ายที่ใช้วิเคราะห์ (ป้าย “ใช้งานหลัก”)
  • สวิตช์ อ่านสกิลจากกราฟิก เปิดไว้เป็นค่าเริ่มต้น ใช้ Gemini เสมอ — ถ้าใช้ OpenAI/Claude อย่างเดียว ส่วนนี้จะถูกข้าม (การวิเคราะห์ส่วนอื่นยังทำงานปกติ)
  • ทุกการเปลี่ยนแปลงมีผลทันที ไม่ต้องปิดเปิดโปรแกรมใหม่
[ภาพ: แท็บตั้งค่า การ์ด Gemini พร้อมปุ่ม “เปลี่ยน key” และ “เปลี่ยนโมเดล”]

6. แก้ปัญหาที่พบบ่อย

อาการวิธีแก้
ดับเบิลคลิกแล้วไม่มีอะไรขึ้น / เบราว์เซอร์ไม่เปิดดูที่มุมขวาล่างของจอ (อาจต้องกดลูกศร ^ ข้างนาฬิกา) ถ้ามีไอคอน Resume AI ให้คลิกขวา → เปิดหน้าเว็บ · ถ้าไม่มี ให้เปิดใหม่อีกครั้ง หรือรีสตาร์ทเครื่อง · ถ้ามีข้อความว่า “พอร์ต 8000 ถูกใช้งานอยู่” ให้ปิดโปรแกรมอื่นแล้วลองใหม่
“API key ใช้ไม่ได้”ตรวจว่าคัดลอก key มาครบ (ไม่มีช่องว่างหัวท้าย) หรือ key ถูกลบไปแล้ว → สร้าง key ใหม่ตามข้อ 2 แล้วเปลี่ยนตามข้อ 5
“โควตาการใช้งานเต็มแล้ว (429)”Gemini แบบฟรีจำกัดจำนวนครั้งต่อนาที/ต่อวัน → รอ 1 นาทีแล้วลองใหม่ · ถ้ายังไม่ได้ ให้เปลี่ยนเป็นโมเดลอื่น (เช่นรุ่น flash-lite) หรือรอวันถัดไป
“ไม่พบโมเดล (404)”โมเดลที่เลือกไว้ถูกปลดระวางแล้ว → แท็บตั้งค่า → เปลี่ยนโมเดล → เลือกตัวที่มี ★
“เชื่อมต่อ … ไม่ได้”ตรวจว่าเครื่องต่ออินเทอร์เน็ตอยู่ (ส่วน AI ต้องใช้อินเทอร์เน็ต) แล้วลองใหม่
ผลภาษาไทยเพี้ยน / ทักษะหายไปเยอะมักเกิดกับไฟล์จาก Canva ที่ฝังตัวอักษรแบบพิเศษ → ใน Canva กด แชร์ → ดาวน์โหลด → เลือก “PDF มาตรฐาน” แล้วลองใหม่ · ถ้ายังเพี้ยน ระบบจะอ่านจากภาพให้เอง (ผลอาจคลาดเคลื่อนเล็กน้อย)
“อ่านข้อความจากไฟล์ PDF นี้ไม่ได้เลย”ไฟล์อาจเสียหาย ตั้งรหัสผ่าน หรือเป็นภาพสแกนที่ไม่ชัด → ขอไฟล์ใหม่จากผู้สมัคร หรือบันทึกเป็น PDF ใหม่

การส่งไฟล์ log ให้ผู้ดูแล

  1. คลิกขวาไอคอน Resume AI ที่มุมขวาล่าง → เปิดโฟลเดอร์ log (หรือแท็บตั้งค่า → “เปิดโฟลเดอร์ log”)
  2. ส่งไฟล์ resume_ai.log (และ resume_ai.log.1 ถ้ามี) ให้ผู้ดูแลทางอีเมลหรือ LINE พร้อมบอกว่าทำอะไรอยู่ตอนเกิดปัญหา

ไฟล์ log ไม่มี API key อยู่ในนั้น (ระบบซ่อนให้อัตโนมัติ) · อยู่ที่ %APPDATA%\ResumeAI\logs\

ถอนการติดตั้ง

Start Menu → Resume AI → ถอนการติดตั้ง Resume AI (หรือ Settings → Apps) — ตอนท้ายโปรแกรมจะถามว่าจะลบการตั้งค่า (API key และ log) ด้วยไหม
